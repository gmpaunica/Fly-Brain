# FB-09 — BANC source and pathway feasibility decision

Date: 2026-09-24  
Original slice: feasibility decision only. Current update (2026-09-26): data
import and FB-09 recovery are verified; see [current status](../../PROJECT_STATUS.md).
The historical source decision below is preserved.

## Scope

Choose a reproducible, licensed Drosophila source and verify that a small
olfactory-to-motor subset can be defined with original neuron identifiers,
directed edges, structural weights and explicit simulator interfaces. This is
the first FB-09 slice only. It does not modify the neural implementation,
train a controller or claim that connectome wiring improves navigation.

## Decision

Use the **BANC v888 adult female brain-and-nerve-cord connectome** from the
final 2026 publication. Pin the static Harvard Dataverse release rather than
the living Codex view:

- Dataset DOI: <https://doi.org/10.7910/DVN/7WTH1N>
- Dataverse dataset version audited: `3.0`, released 2026-07-01
- License reported by that release: **CC BY 4.0**
- Metadata: `banc_888_meta.feather`, Dataverse file `14033740`, 57,550,610
  bytes, MD5 `6275eda42f98c49539d1ab513d979d09`
- Connectivity: `banc_888_edgelist_simple_v2.feather`, Dataverse file
  `13992792`, 305,250,378 bytes, MD5
  `394406f8a9bdf093c895f95aff4f6c49`

The publication uses materialization v888 for the final paper and states that
the downloadable archive includes metadata and synaptic edge lists. The v2
synapse detector is selected because the paper's analyses use it. The audit
read 188,508 metadata rows and 11,752,828 directed edge rows. Future imports
must verify the pinned sizes and hashes before parsing.

### Alternatives considered

| Source | Strength | Blocking limitation for this task |
|---|---|---|
| **BANC v888** | One female specimen includes brain, neck connective, VNC, sensory neurons, DNs and motor neurons; static DOI archive | Newer living resource; some annotations and reconstructions carry explicit quality flags |
| FlyWire FAFB v783 | Mature whole-brain annotations and stable root IDs | Brain volume stops before the VNC, so it cannot verify an in-dataset motor endpoint; public data is CC BY-NC 4.0 |
| neuPrint hemibrain v1.2.1 | Mature query tooling and central-brain cell types | Partial central brain, token-based API workflow and no complete brain-to-leg-motor corridor in one specimen |

BANC is the only candidate examined here that satisfies both sensory input and
named motor endpoint coverage without joining different animals or datasets.

## Source semantics

- `root_888` is retained as an opaque string ID. It must never be converted to
  floating point. A contiguous tensor index is a derived field only.
- An edge is directed `pre -> post`. FlyBrain stores it at
  `W[post_index, pre_index]`.
- `count` is the number of reported synapses for the pair. In this edge file,
  `norm = count / post_count`, the fraction of the postsynaptic cell's input.
- Keep only edges with `count >= 5` for the first import. This matches the
  BANC paper's influence analysis threshold for reducing reconstruction or
  biological noise.
- Preserve raw `count`, `norm`, predicted/verified transmitter, confidence,
  proofread state, status flags, cell type, side and endpoint annotations in
  provenance even when the simulator does not consume them.
- Synapse count is a structural measure, not a measured physiological weight.
  Transmitter identity does not by itself determine receptor-specific sign,
  strength or time constant. The first import is therefore explicitly an
  **unsigned structural baseline**, not a signed biological network.

The proposed simulation tensor is
`W[post, pre] = connectome_gain * norm` for retained edges. All entries are
non-negative initially, following the source paper's structural influence
analysis. `connectome_gain` is hand-written simulation scaffolding and must be
chosen by a predeclared propagation/stability test, not by navigation results.
Raw counts and normalized fractions remain available for later signed or
biophysical variants.

## Proposed 83-neuron subset

The selection is deterministic against the pinned files:

1. Select `proofread == TRUE`, `cell_type == ORN_VA2` neurons separately by
   side. Retain only cells with a direct edge of at least 10 synapses to the
   ipsilateral `VA2_adPN`. This gives 31 left and 37 right ORNs. Left root
   `720575941537542888` is excluded because it lacks that qualifying edge and
   carries sensory tracing/unrooted flags.
2. Retain the two `VA2_adPN` cells and the explicitly pinned corridor root IDs
   in the table below. Verify each corridor edge has `count >= 10`. The first
   feasibility pass incorrectly described these paths as the output of a
   strongest-first shortest-path search. Replaying that rule on the pinned
   archive gives a different left route of the same hop count; the curated
   path IDs, rather than that search rule, define this 83-cell artifact.
3. Retain the strongest direct DNa02 target for each ipsilateral front,
   middle and hind leg whose annotation says `move_coxa_anterior`.
4. After selecting nodes, retain every internal directed edge with
   `count >= 5`, including source-reported self-edges.

This produces 68 ORNs, 2 projection neurons, 5 corridor neurons, 2 DNa02
neurons and 6 motor neurons: **83 nodes, 176 retained edges and 6,062 summed
synapse counts**. Thirty-one retained rows are self-edges; they remain visible
and testable rather than being silently discarded.

## Simulator interface

- `odor_left` drives only the 31 selected left ORNs; `odor_right` drives only
  the 37 selected right ORNs. No position, heading, target bearing or world
  object crosses this boundary.
- The existing LIF rules remain hand-written. BANC supplies topology, IDs and
  structural counts; it does not supply membrane parameters, delays,
  thresholds, reset rules or receptor-specific signs.
- A topology-dependent motor interface must exclude the present charge
  features, which directly reconstruct bilateral sensory drive and made FB-08
  insensitive to downstream rewiring. A first diagnostic decoder should use
  only DNa02 and selected motor-endpoint activity.
- For turn, the biologically motivated observable is the right-minus-left
  DNa02 activity difference: left DNa02 activity predicts left turns and right
  DNa02 activity predicts right turns. FlyBrain's positive turn is right.
- For forward, mean activity of the six `move_coxa_anterior` motor endpoints
  is only an engineered proxy. The 2D point-body model has no legs, muscles,
  gait phase or proprioception, so it cannot claim a biological motor decode.

## Missing links and risks

- The BANC specimen was unusually right-turn biased in its recorded Y-maze
  behavior. Its left/right structural asymmetries must not be generalized to
  the species from one animal.
- The selected left and right corridors differ in hop count and cell types.
  This may reflect biology, reconstruction/annotation state or the path rule.
- BANC reports chemical synapses but does not provide the receptor map needed
  for validated edge signs. Gap junctions, extrasynaptic modulation and full
  neuron dynamics are outside this import.
- Generic simulated food odor is not a calibrated VA2 ligand concentration.
  Equal current within each ORN pool is scaffolding.
- DNa02 has good experimental support for ipsilateral steering, but the six
  motor endpoints do not define a complete walking gait or a 2D velocity law.
- Root IDs are stable only for materialization v888. A later BANC snapshot is
  a new source version and requires an explicit migration, not silent refresh.
- The route selection establishes graph reachability, not useful dynamics,
  learning or a topology advantage.

## Next implementation slice and gates

Implement a loader/transform against small checked-in fixtures derived from
the pinned source, without adding the 300 MB archive to the repository. The
import slice should:

1. verify source metadata, license, version and checksums;
2. preserve root IDs and metadata while assigning deterministic contiguous
   indices;
3. reject malformed, duplicate, missing-endpoint and reversed edges;
4. prove `pre -> post` becomes `W[post, pre]` with audited tiny-edge tests;
5. reproduce the 83-node/176-edge audit and the anchor paths above;
6. separate source `count`/`norm` from synthetic `connectome_gain` and LIF
   parameters;
7. test reset, directed propagation and stability before embodied evaluation;
8. evaluate a topology-dependent output against matched randomized and
   ablated controls before making any connectivity-benefit claim.

No long training or fresh behavioral evaluation is authorized by this plan.

## Import outcome — 2026-09-24

The checked-in [subset](../../src/flybrain/data/banc_v888_va2_dna02.json) is
90,011 bytes (SHA-256
`76c254e22741230b3d97aeb21c9938405b2e98c07ca29b8cde9331f3c4e6d0ae`).
The [extractor](../../scripts/build_banc_subset.py) verifies both full-source
files against their pinned sizes and MD5 hashes, selects the declared cells,
and reproduces 83 nodes, 176 edges, 6,062 synapses and 31 self-edges. Running
it twice produced the same artifact hash. The Python loader checks provenance,
IDs, directions, counts and audit anchors; `BancNetwork` uses the existing LIF
population and bilateral odor encoder. The full archive stays outside the
package in temporary research storage.

A bounded dynamics probe at gain 1 and 600 used 100 neural steps of left odor
at concentration 0.025, then 100 silent steps. Gain 1 produced 217 left ORN
spikes and zero projection, DNa02 or motor spikes. Gain 600 reached those cells
but also produced 83 right DNa02 spikes and 246 right motor spikes during the
left-input interval; activity persisted throughout the silent interval.
Both runs remained numerically finite. This fails selective propagation and
washout, so no gain is accepted as a usable behavioral setting. The next task
is a predeclared dynamics recovery, then a topology-dependent decoder and
teacher/baseline checks before any new training. See the
[recorded probe](../../experiments/fb09-gain-probe/results.json).
