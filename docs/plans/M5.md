# M5 plan: simultaneous world and synthetic brain view

## Goal

Show the existing hand-built 100-neuron network beside the world, using its
real accumulated spike counts and causal motor command. The panel is a
functional diagram of the synthetic graph, not an anatomical fruit-fly brain.

## Boundaries

- Neural mode uses an 800 x 600 world viewport and a 400 x 600 brain panel.
- Manual mode keeps its existing 800 x 600 window and Torch-free import path.
- The viewer receives immutable `ClosedLoopSnapshot` values. Drawing cannot
  advance physics, neural state, visual time, or any random generator.
- Activity fades only when neural simulation time advances. Repeated display
  frames leave it unchanged.
- Every completed world tick reaches the viewer, including multiple ticks
  accumulated before one display frame.
- Positions are a deterministic group diagram. No anatomical coordinates or
  downloaded connectome data are represented.
- The panel limits connections to 80 deterministic, group-balanced edges.

## Implemented checks

- [x] Real nonzero spike counts light the matching neurons.
- [x] Activity fades by elapsed neural time and is unchanged by extra draws.
- [x] Every snapshot produced by a multi-tick frame is returned for aggregation.
- [x] Sensory, interneuron, and motor groups retain distinct colours when active.
- [x] Tick, neural step, simulation time, motor-group activity, and decoded
  command are visible.
- [x] Reset clears visual traces and displayed motor output.
- [x] Edge selection and node layout are deterministic and use no randomness.
- [x] Extra brain draws leave world and neural trajectories identical.
- [x] Manual and neural 120-tick headless smokes complete exactly.
- [x] An exact-size 1200 x 600 rendered frame was visually inspected.
