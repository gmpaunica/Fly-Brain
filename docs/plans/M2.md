**Goal:** One static odor source, two independently sampled antennae, live readings.

**Architecture:** Immutable source and sensory observation; pure world sampling.
Simulation publishes current-pose readings after movement and on initialization/
reset. Rendering reads those readings and draws source/antenna markers.

**Tech stack:** Existing Python 3.12/Pygame/pytest; no additional dependencies.

**Spec:** `docs/architecture.md` M2 and original brief sections 7, 8 and M2.

## Decisions and interfaces

- `world/odor.py`: immutable `OdorSource(x, y, strength=1000, softening=20)` with
  `sample(x, y) -> float`: strength / (distance squared + softening squared).
  Positive softening, nonnegative strength, finite coordinates/parameters/peak.
  Stable hypot/division evaluation avoids squared-distance overflow. Field extends
  outside walls; antenna points are not clamped.
- `world/sensing.py`: immutable `SensoryObservation(odor_left, odor_right)` with
  only two finite nonnegative concentrations; `sample_odor(fly, source)` samples
  each point independently. No coordinate/heading/source fields in observation.
- `Fly.antenna_positions()` returns left/right world points. Forward offset 10,
  lateral offset 5; left vector `(sin(h), -cos(h))`. Synthetic geometry/field units.
- Optional `odor_source` appended to simulation constructor keeps prior API.
  No source produces zero readings. `observation` describes current/post-movement
  pose; no controller exists. M4 must separately sample before neural inference.
- App source at (0.75 * width, 0.5 * height), fixed through reset. No source
  consumption/success/reward. Raw readings, no normalization or steering answer.
