# FB-08: frozen-readout ablation and perturbation experiments

Date: 2026-09-23. Authorized by the user's request to proceed to the next FB
section. M6's fresh matched navigation gate has passed. App checkpoint
integration is optional and is not a prerequisite for this renderer-free task.

## Hypothesis and boundary

The saved charge readout relies on bilateral sensory drive more than on the
downstream synthetic connections. Predict that removing both sensory inputs
reduces arrivals by at least 8/16 relative to intact, while removing downstream
synapses reduces arrivals by at most 2/16. These are descriptive engineering
thresholds for this one assay, not population significance tests. Report either
outcome without choosing a replacement hypothesis or tuning the model.

Use the original trained schema-3 checkpoint, frozen CPU weights, graph seed
7, gain-1 motor mapping, 600-tick horizon and the existing world configuration.
Exactly 16 new diagnostic starts use seeds 51000-51015: local random generator,
uniform angle, radius sqrt(uniform(60**2,180**2)), then uniform heading around
source (600,300). All conditions use identical cases. These are exploratory
intervention cases, not another M6 final set; old final cases are not reused.

## Locked conditions and budget

1. Intact saved controller.
2. Left sensory external drive zeroed.
3. Right sensory external drive zeroed.
4. Both sensory external drives zeroed.
5. All synapses zeroed (sensory drive and tonic forward drive remain).
6. Sensory-to-interneuron synaptic weights multiplied by 0.5.
7. The same pathway multiplied by 2.0.
8-10. Three random-wiring controls, local seeds 701, 702, 703. Independently
permute each interneuron row's 20 sensory-source columns and each left/right
motor row's 50 interneuron-source columns. Preserve each row's weight values,
nonzero count, layer direction, labels, signs and zero sensory incoming rows;
do not preserve source out-degree or left/right block structure.

Changes are applied to a fresh experimental network per episode. Checkpoint
loading validates its original contract first; altered wiring is an explicit
intervention with its own weight hash, not a newly trained compatible model.
Sensory ablation removes external neural current; neurons still follow the
same equations. The learned decoder receives actual neural activity only.

Ceiling: 160 episodes / 96,000 world ticks, **zero optimizer updates**. Write
exact cases, interventions, hashes and software to protocol JSON before any
episode. Run intact first and require >=13/16 arrivals to establish that the
assay works; otherwise record and stop for user input. Abort on nonfinite
output, integrity mismatch or budget breach. Never retry or tune automatically.

## Metrics and acceptance

Record per-case arrivals, ticks, progress, final distance, collision ticks,
spikes and success-only time/efficiency with explicit denominators. Report
paired success losses/gains and mean progress changes relative to intact.
Keep three random wirings separate; summarize their range without treating
48 correlated episodes as 48 independent starts. No topology-benefit claim
from absence of a loss, and no broad biological inference.

Tests must establish intact equivalence, real sensory-current ablation,
pathway-only gains, rewiring constraints/local RNG/reset, matched output
records, failure stopping and artifact preservation. Run targeted and full
tests. Generate PNG/SVG plots from saved results using optional Matplotlib;
inspect the plot. Record conclusions and update status/log/queue/decisions.
Completing FB-08 means producing valid reproducible experiments and plots,
even if the predicted intervention effects do not occur. Stop before FB-09.
